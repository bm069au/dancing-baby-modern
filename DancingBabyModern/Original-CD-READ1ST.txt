LAST MINUTE INSTALL NOTES
=========================
During the Installation Process you will be given two options:
Regular Install or Full Install. This CD contains over 150 Dancing
Baby animations and those video files take up a lot of space!

The "Regular Install" option will require 16MB and installs 10
of the most popular animations.

The "Full Install" option will install a larger selection of
animations and requires over 60MB. If you have the hard drive
space, go for it, there are some pretty hilarious animations.

Either way, you can easily delete the animations you don't want
and add the ones you do by simply deleting/copying the appropriate
files. Full details on adding/removing animations can be found
by reading the README File or by clicking on "Help" from within
the progam itself.

Be sure to explore the "More Animations" and "More Animations 2"
folders on the CD to see many more animations!
