DANCING BABY - CURRENT WINDOWS ADAPTATION

1. Keep this entire folder together in a permanent location.
2. Double-click Configure.cmd. Pick an animation; the original dance is
   029_BABYCHA1. Try Preview full screen. Move the mouse or press a key to exit.
3. Click Save and close.
4. Right-click DancingBaby.scr and choose Install (possibly under Show more
   options). Windows opens its Screen Saver Settings. Choose your wait time.
   Enable "On resume, display logon screen" if you want Windows to lock.

Keep the Videos and Music folders beside DancingBaby.scr. Do not copy the
screensaver alone into System32. If you move the folder, select your animation
and music again and reinstall it from the new location.

Silent by default. Settings can enable a MIDI/WAV song or the animation's own
sound. Music takes priority over the animation audio. Selected music loops.
Shuffle changes animation at the end of a loop after approximately 30 seconds.
The same animation appears on each connected monitor, preserving its shape.
Original low-resolution graphics are preserved; this is not an HD remake.

Requires 64-bit Windows 10/11, .NET Framework 4.8 and Windows media playback
components (Windows N editions may require the Media Feature Pack).
Settings are stored under %LOCALAPPDATA%\DancingBabyModern\settings.json.

Validation: 203 original video files reduced to 194 unique files by SHA256;
all 194 converted to H.264/AAC successfully. Windows media playback opened and
rendered the classic 260x200 dance in a bounded automated check. Full-screen
exit, Windows preview/install, mixed-DPI multiple monitors and music still need
your manual check. Original-CD-README.txt and Original-CD-READ1ST.txt retain the
original authorship and notices. Original software/installers were not run.
